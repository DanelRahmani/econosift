## 2. Technical Indicators (Markets & Screener)

| Term | Definition |
|------|------------|
| **MACD** | Moving Average Convergence Divergence — trend-following momentum indicator showing the relationship between two exponential moving averages |
| **MACD Signal Line** | 9-period EMA of the MACD line; used to generate buy/sell signals |
| **MACD Histogram** | Visual representation of the difference between the MACD line and its signal line |
| **RSI (Relative Strength Index)** | Momentum oscillator measuring the speed and magnitude of price changes (0–100); >70 = overbought, <30 = oversold |
| **RSI-14** | 14-day Relative Strength Index |
| **Bollinger Bands** | Volatility bands placed at ±2 standard deviations around a simple moving average |
| **Bollinger %B** | Indicates where price sits within the bands (0 = lower, 1 = upper) |
| **Bollinger Squeeze** | When bandwidth narrows significantly, suggesting a breakout may be imminent |
| **Ichimoku Cloud (Ichimoku Kinko Hyo)** | Comprehensive technical indicator showing support/resistance, trend direction, and momentum |
| **Tenkan-sen (Conversion Line)** | (9-period high + 9-period low) / 2 in Ichimoku system |
| **Kijun-sen (Base Line)** | (26-period high + 26-period low) / 2 in Ichimoku system |
| **Senkou Span A (Leading Span A)** | (Tenkan + Kijun) / 2 plotted 26 periods ahead |
| **Senkou Span B (Leading Span B)** | (52-period high + 52-period low) / 2 plotted 26 periods ahead — forms the cloud |
| **Chikou Span (Lagging Span)** | Current closing price plotted 26 periods behind |
| **Ichimoku Bullish** | Price above the cloud, Tenkan > Kijun |
| **Ichimoku Bearish** | Price below the cloud, Tenkan < Kijun |
| **Fibonacci Retracement Levels** | Horizontal lines at 23.6%, 38.2%, 50%, 61.8%, 78.6% indicating potential support/resistance |
| **Fibonacci Extension Levels** | Projections beyond 100% for price targets |
| **Pivot Points (Classic)** | Calculated from the previous period's high, low, and close to identify potential support (S1, S2) and resistance (R1, R2) levels |
| **Stochastic RSI (StochRSI)** | RSI of the RSI — more sensitive oscillator indicating overbought/oversold conditions |
| **Williams %R** | Momentum oscillator measuring overbought/oversold levels (-80 to -100 = oversold, -0 to -20 = overbought) |
| **OBV (On-Balance Volume)** | Cumulative volume indicator that adds/subtracts volume based on price direction |
| **OBV Divergence** | When price makes a new high but OBV does not confirm, suggesting weakening momentum |
| **CMF (Chaikin Money Flow)** | Volume-weighted indicator measuring accumulation/distribution over 20 periods |
| **CMF+** | Positive Chaikin Money Flow (buying pressure) |
| **ATR (Average True Range)** | Volatility indicator measuring the average range between high and low over a period |
| **SMA (Simple Moving Average)** | Average price over a specified number of periods |
| **SMA-50** | 50-day simple moving average |
| **SMA-200** | 200-day simple moving average |
| **Golden Cross** | When the 50-day SMA crosses above the 200-day SMA — bullish signal |
| **Death Cross** | When the 50-day SMA crosses below the 200-day SMA — bearish signal |
| **52-Week High/Low** | The highest/lowest price a stock has traded at over the past 52 weeks |
| **% from 52-Week High** | Percentage distance from current price to the 52-week high |
| **Normalised Price (Base 100)** | Price series scaled so the starting point = 100, enabling comparison across assets |
| **Week-52 Position** | Where current price sits as a percentage between the 52-week low and high |

## 3. Valuation Models

| Term | Definition |
|------|------------|
| **DCF (Discounted Cash Flow)** | Valuation method projecting future free cash flows and discounting them to present value |
| **Two-Stage DCF** | DCF model with a high-growth stage 1 period followed by a stable terminal growth stage |
| **WACC (Weighted Average Cost of Capital)** | Blended cost of debt and equity financing used as the discount rate in DCF |
| **Cost of Equity** | Expected return demanded by equity investors (calculated via CAPM) |
| **Cost of Debt** | After-tax interest rate the company pays on its borrowings |
| **CAPM (Capital Asset Pricing Model)** | Model: Expected Return = Risk-Free Rate + Beta × (Market Return − Risk-Free Rate) |
| **CAPM Implied Return** | Expected return derived from the CAPM formula |
| **Gordon Growth Model (GGM)** | Dividend discount model assuming perpetual constant growth |
| **DDM (Dividend Discount Model)** | Valuation model based on present value of expected future dividends |
| **FCF (Free Cash Flow)** | Cash generated by operations minus capital expenditures |
| **TTM FCF (Trailing Twelve Months FCF)** | Free cash flow over the most recent four quarters |
| **Terminal Growth Rate** | Perpetual growth rate applied to cash flows beyond the projection period |
| **Stage 1 / Stage 2 (DCF)** | High-growth period (Stage 1) followed by stable growth (Stage 2) in two-stage DCF |
| **Enterprise Value (EV)** | Market cap + total debt − cash & equivalents |
| **Equity Value** | Enterprise value minus net debt |
| **Intrinsic Value** | Estimated true per-share value from a valuation model |
| **Upside / Downside %** | Percentage difference between intrinsic value and current market price |
| **Fair Value / Fairly Valued** | Price is in line with estimated intrinsic value |
| **Undervalued** | Current price is below estimated intrinsic value |
| **Overvalued** | Current price is above estimated intrinsic value |
| **Significantly Undervalued / Overvalued** | Extreme deviation from fair value estimate |
| **EconoSift Composite Fair Value** | Composite weighted-average valuation from all 8 models + CAPM |
| **Sensitivity Heatmap/Grid** | Matrix showing how DCF value changes across different WACC/growth assumptions |
| **8-Model Valuation Engine** | Suite of 8 distinct valuation models aggregated into a composite fair value |
| **Moody's AAA Yield** | Yield on Moody's AAA-rated corporate bonds (used as credit spread reference) |
| **Damodaran ERP** | Aswath Damodaran's equity risk premium estimates by country |
| **Sector Multiples** | Industry-average EV/EBITDA and other multiples used for relative valuation |
| **Locked Model** | A valuation model that could not be computed (missing required inputs) |

## 4. Fundamental Financial Ratios

| Term | Definition |
|------|------------|
| **P/E (Price-to-Earnings)** | Stock price divided by earnings per share (trailing) |
| **Forward P/E** | Stock price divided by expected (forward) earnings per share |
| **Trailing EPS** | Earnings per share over the trailing twelve months |
| **Forward EPS** | Estimated earnings per share for the next fiscal year |
| **P/B (Price-to-Book)** | Stock price divided by book value per share |
| **EV/EBITDA** | Enterprise value divided by EBITDA (earnings before interest, taxes, depreciation, amortization) |
| **EV/FCF** | Enterprise value divided by free cash flow |
| **FCF Yield** | Free cash flow per share divided by stock price — cash return version of earnings yield |
| **P/S Ratio (Price-to-Sales)** | Stock price divided by revenue per share |
| **Dividend Yield** | Annual dividend per share divided by stock price |
| **ROE (Return on Equity)** | Net income divided by shareholders' equity |
| **ROA (Return on Assets)** | Net income divided by total assets |
| **ROIC (Return on Invested Capital)** | NOPAT divided by invested capital — measures capital efficiency |
| **NOPAT (Net Operating Profit After Tax)** | Operating profit adjusted for taxes |
| **Invested Capital** | Total capital invested in the business (debt + equity − cash) |
| **Gross Margin** | (Revenue − COGS) / Revenue |
| **Operating Margin** | Operating income / Revenue |
| **Net Margin** | Net income / Revenue |
| **Revenue Growth (%)** | Year-over-year percentage change in revenue |
| **EPS Growth (%)** | Year-over-year percentage change in earnings per share |
| **Debt-to-Equity (D/E)** | Total debt divided by shareholders' equity |
| **Debt-to-Assets** | Total debt divided by total assets |
| **Interest Coverage** | Operating income divided by interest expense |
| **Net Debt / EBITDA** | (Total debt − cash) divided by EBITDA |
| **Current Ratio** | Current assets divided by current liabilities |
| **Quick Ratio** | (Current assets − inventory) divided by current liabilities |
| **Cash Ratio** | Cash and equivalents divided by current liabilities |
| **Operating CF Ratio** | Operating cash flow divided by current liabilities |
| **Asset Turnover** | Revenue divided by total assets |
| **Inventory Turnover** | Revenue divided by inventory |
| **Receivables Turnover** | Revenue divided by accounts receivable |
| **Short % of Float (Short Float)** | Percentage of outstanding shares sold short |
| **Short Ratio** | Number of days to cover all short positions (short interest / average daily volume) |
| **Book Value** | Total assets minus intangible assets and liabilities |
| **Market Cap** | Total market value of outstanding shares (price × shares outstanding) |
| **Average Volume** | Average number of shares traded per day (typically 20-day or 3-month) |
| **Volume Ratio** | Current volume divided by average volume |

## 5. Risk Metrics

| Term | Definition |
|------|------------|
| **Value at Risk (VaR 95%)** | Maximum expected loss with 95% confidence over a given period |
| **Value at Risk (VaR 99%)** | Maximum expected loss with 99% confidence |
| **CVaR (Conditional VaR) / Expected Shortfall** | Average loss beyond the VaR threshold (tail risk) |
| **Sharpe Ratio** | (Return − Risk-Free Rate) / Volatility — risk-adjusted return measure |
| **Sortino Ratio** | Like Sharpe but uses only downside deviation (penalizes only negative volatility) |
| **Beta** | Measure of asset volatility relative to the market (β = 1 = market moves) |
| **Alpha (Jensen's Alpha)** | Excess return above what the CAPM predicts |
| **Annualised Alpha** | Alpha multiplied by 252 trading days to annualize |
| **Treynor Ratio** | (Return − Risk-Free Rate) / Beta — risk-adjusted return using systematic risk |
| **Calmar Ratio** | Annualised return divided by maximum drawdown |
| **Omega Ratio** | Ratio of probability-weighted gains to losses relative to a threshold |
| **Maximum Drawdown** | Largest peak-to-trough decline in value |
| **Annualised Volatility** | Standard deviation of returns annualized (×√252) |
| **Annualised Return** | Average daily return annualized (×252) |
| **Daily Mean Return** | Average daily log return |
| **Systematic Variance** | Portion of total variance explained by market (beta² × market variance) |
| **Idiosyncratic Variance** | Portion of total variance unique to the asset (total − systematic) |
| **R² (R-Squared)** | Proportion of return variance explained by the benchmark |
| **Rolling Metrics** | Risk metrics computed over a sliding window (20D, 60D, 120D, 252D) |
| **Correlation Matrix** | Pairwise Pearson correlation heatmap between assets |
| **GARCH(1,1)** | Generalized Autoregressive Conditional Heteroskedasticity model — volatility forecasting |
| **Omega (GARCH)** | GARCH constant term |
| **Alpha (GARCH)** | GARCH coefficient for lagged squared returns |
| **Beta (GARCH)** | GARCH coefficient for lagged variance |
| **Forecast Vol (GARCH)** | One-step-ahead volatility forecast from GARCH model |
| **Hurst Exponent** | Measure of long-term memory in time series (H<0.4 = mean-reverting, H≈0.5 = random walk, H>0.6 = trending) |
| **Ornstein-Uhlenbeck (OU) Process** | Mean-reverting stochastic process used for pairs trading |
| **Theta (OU)** | Mean-reversion speed |
| **Mu (OU)** | Long-run mean level |
| **Half-Life (OU)** | Time in days for a deviation to revert halfway back to the mean |
| **Cointegration Test (Engle-Granger)** | Statistical test for whether two assets share a common long-term equilibrium |
| **Hedge Ratio (Cointegration)** | Weighting ratio between two cointegrated assets |
| **Spread (Cointegration)** | Residual series from cointegrated pair |

## 6. Options & Implied Volatility

| Term | Definition |
|------|------------|
| **IV (Implied Volatility)** | Market's forecast of future volatility derived from option prices |
| **IV 30** | 30-day implied volatility |
| **IV Rank** | Current IV relative to its range over the past year (0–100) |
| **IV Percentile** | Percentage of days over the past year that IV was below the current level |
| **ATM (At-the-Money)** | Option whose strike price is closest to the current spot price |
| **ITM (In-the-Money)** | Option with intrinsic value (call: strike < spot, put: strike > spot) |
| **OTM (Out-of-the-Money)** | Option with no intrinsic value |
| **Moneyness** | Ratio of strike price to spot price |
| **Open Interest (OI)** | Total number of outstanding option contracts |
| **Put/Call OI Ratio** | Total put open interest divided by call open interest (sentiment indicator) |
| **Max Pain** | Strike price where option buyers would experience the maximum financial loss at expiry |
| **Implied Move** | Expected price move implied by ATM straddle price |
| **Straddle** | Combined long call + long put at the same strike and expiry |
| **Delta** | Option price sensitivity to a $1 change in the underlying (0 to 1 for calls, -1 to 0 for puts) |
| **Gamma** | Rate of change of delta per $1 move in the underlying |
| **Theta** | Time decay — option price erosion per calendar day |
| **Vega** | Option price sensitivity to a 1% change in implied volatility |
| **Rho** | Option price sensitivity to a 1% change in interest rates |
| **Black-Scholes Price** | Theoretical option price calculated using the Black-Scholes formula |
| **CRR (Cox-Ross-Rubinstein) Binomial Tree** | Discrete-time option pricing model allowing early exercise (American-style) |
| **Brent's Method** | Numerical root-finding algorithm used to back-solve implied volatility |
| **IV Backsolve** | Reverse-engineering IV from an option's market price |
| **IV Smile** | Pattern of IV across strikes (usually higher for deep OTM/ITM options) |
| **IV Term Structure** | Pattern of IV across different expiration dates |
| **Options Chain** | Table of all available call and put options for a given ticker and expiry |
| **Monte Carlo Options Pricing** | Simulated option price using random price paths |
| **Expiry (DTE — Days to Expiry)** | Number of calendar days until option expiration |
| **Bid / Ask / Mid / Last** | Option prices: bid (buyer will pay), ask (seller wants), mid (average), last (last traded) |
| **OI Profile** | Chart showing open interest concentration across strikes |
| **~15min Delay (Options)** | Note that option data is delayed approximately 15 minutes (free data tier) |

## 8. Yield Curve & Fixed Income

| Term | Definition |
|------|------------|
| **Yield Curve** | Graph of bond yields across different maturities (1m to 30y) |
| **Treasury Yield** | Yield on US government debt at a specific tenor |
| **Tenor** | Maturity length of a bond (3m, 2y, 5y, 10y, 30y, etc.) |

| **TIPS (Treasury Inflation-Protected Securities)** | US government bonds whose principal adjusts with inflation |
| **Real Yield (TIPS Yield)** | Yield on TIPS — nominal yield minus expected inflation |
| **Breakeven Inflation (5Y / 10Y / 30Y)** | Difference between nominal yield and TIPS yield — market-implied inflation expectation |
| **5Y5Y Forward Breakeven** | Market-implied inflation expectation 5 years from now, for the following 5 years |
| **ACM Term Premium** | New York Fed's Adrian-Crump-Moench decomposition of term premium in 10-year yields |
| **ACM Expectations Component** | Portion of 10-year yield attributable to expected short-term rate path |
| **US Spot Curve** | Current US Treasury yield curve across 11 standard tenors |
| **Foreign 10Y Yields** | 10-year government bond yields for Germany, UK, Japan, France, Italy, Canada, Australia, Spain |
| **IG OAS (Investment Grade Option-Adjusted Spread)** | Credit spread of investment-grade corporate bonds over Treasuries |
| **HY OAS (High Yield Option-Adjusted Spread)** | Credit spread of high-yield (junk) bonds over Treasuries |
| **BBB Spread** | Credit spread for BBB-rated corporate bonds |
| **TED Spread** | Difference between 3-month LIBOR and 3-month T-bill rate (banking stress indicator) |
| **SOFR (Secured Overnight Financing Rate)** | Benchmark US overnight interest rate (replaced LIBOR) |
| **SOFR-FF Spread** | SOFR minus Fed Funds rate |
| **CP Spread (Commercial Paper Spread)** | CP3M minus Fed Funds rate — short-term credit stress indicator |
| **CPF3M** | 3-month AA-rated commercial paper yield |
| **DTB3 (3-Month T-Bill)** | 3-month US Treasury bill secondary market rate |
| **Funding Spread** | Difference between short-term funding rates and risk-free benchmark |
| **M2 Money Supply** | Broad measure of US money supply (cash, checking deposits, savings, money market) |
| **M2 YoY** | Year-over-year percentage change in M2 money supply |

## 11. Portfolio Theory & Analytics

| Term | Definition |
|------|------------|
| **Efficient Frontier** | Set of optimal portfolios offering the highest expected return for a given risk level |
| **Mean-Variance Optimization** | Portfolio construction balancing expected return against variance |
| **Max Sharpe Portfolio** | Portfolio on the efficient frontier with the highest risk-adjusted return |
| **Global Minimum Variance Portfolio** | Portfolio with the lowest possible volatility |
| **Black-Litterman Model** | Portfolio optimization that combines market equilibrium with investor views |
| **Equilibrium Return** | Expected return implied by CAPM from current market weights |
| **BL Return** | Black-Litterman-adjusted expected returns after incorporating investor views |
| **Optimal Weights** | Portfolio weights that maximize risk-adjusted return |
| **Monte Carlo Simulation** | Generating thousands of random portfolio outcomes to estimate risk/return distribution |
| **Kelly Criterion** | Formula for optimal bet size to maximize long-run growth |
| **Kelly Fraction** | Optimal allocation percentage per the Kelly formula |
| **Fama-French 3-Factor Model** | Alpha + Mkt-RF × βᵐᵏᵗ + SMB × βˢᵐᵇ + HML × βʰᵐˡ |
| **Fama-French 5-Factor Model** | 3-factor plus RMW (profitability) and CMA (investment) |
| **Mkt-RF (Market Risk Premium Factor)** | Market return minus risk-free rate |
| **SMB (Small Minus Big)** | Small-cap minus large-cap return factor |
| **HML (High Minus Low)** | Value minus growth return factor |
| **RMW (Robust Minus Weak)** | High profitability minus low profitability factor |
| **CMA (Conservative Minus Aggressive)** | Low investment minus high investment factor |
| **Factor Loading** | Sensitivity of a portfolio/asset to a specific factor (beta coefficient) |
| **t-Stat (t-Statistic)** | Coefficient divided by standard error — tests statistical significance |
| **CAPM Attribution** | Decomposition of returns into market beta + alpha components |
| **Systematic Risk %** | Percentage of total risk explained by market exposure |
| **Idiosyncratic Risk %** | Percentage of total risk unique to the portfolio |
| **Risk Contribution** | Each asset's share of total portfolio risk |
| **Marginal Risk Contribution** | Change in portfolio risk per unit change in an asset's weight |
| **% Risk Contribution (% Contrib)** | Percentage of total portfolio variance attributable to each holding |
| **Correlation** | Statistical measure (-1 to +1) of how two assets move together |
| **Pearson Correlation** | Standard linear correlation coefficient |
| **Underwater Curve / Drawdown Chart** | Chart showing decline from peak portfolio value |
| **Total Return** | Cumulative percentage return over the full period |
| **Contribution (Portfolio)** | Weight × asset total return — how much each holding contributed to overall return |

## 12. Research Strategies

| Term | Definition |
|------|------------|
| **Risk Parity** | Portfolio strategy allocating risk (not capital) equally across assets |
| **ERC (Equal Risk Contribution)** | Each asset contributes the same amount of portfolio risk (via SLSQP optimization) |
| **Inverse Vol Weighting** | Weights proportional to 1/σ (each asset weighted inversely to its volatility) |
| **60/40 Benchmark** | Classic 60% equity (SPY) / 40% bond (AGG) portfolio benchmark |
| **Monthly Rebalance** | Portfolio weights reset to targets at the start of each month |
| **Period (Backtest)** | Time window over which the strategy is evaluated (1Y, 3Y, 5Y, etc.) |
| **FX Carry Trade** | Borrowing low-yield currencies and lending high-yield currencies |
| **G10 Carry Table** | Interest rate differentials across all G10 currency pairs |
| **Long Top-3 / Short Bottom-3 (Carry)** | Going long the 3 highest-carry currencies and short the 3 lowest |
| **Cross-Sectional Momentum** | Ranking stocks by past returns (1M, 3M, 6M, 12M-1M) and sorting into deciles |
| **Signal (Momentum)** | Prior return used to rank stocks (1m, 3m, 6m, or 12m1m skip-month) |
| **Deciles (Momentum)** | Ten groups from weakest (1) to strongest (10) momentum |
| **12M-1M (Skip-Month Momentum)** | Classic momentum: prior 12 months minus the most recent month |
| **Realized Moments** | Statistical moments computed from historical price data |
| **Garman-Klass Variance** | OHLC-based realized variance estimator: 0.5 × ln(H/L)² — (2ln2−1) × ln(C/O)² |
| **Realized Skewness** | Rolling skewness of daily returns |
| **Realized Excess Kurtosis** | Rolling excess kurtosis (fat tails) of daily returns |
| **Cross-Sectional Tail-Return Test** | Sorting stocks by prior realized skew to test the MAX/MIN effect |
